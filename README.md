# CP390 Week 10 Starter Repository

Practice repository for the Week 10 lab in CP390 Software Development and Deployment.

## How to use it
- IMPORT this repository into your own GitHub account (lab Part 2). Do not fork it and do not open pull requests here.
- Clone YOUR imported copy, complete glossary.txt, commit, and push to YOUR copy.

## Files
- glossary.txt: GitHub terms to define in your own words
- git-cheatsheet.txt: the Git commands used in this lab
- .gitignore: tells Git which files to ignore
- LICENSE: MIT licence

## Branches and tags
- main: the branch you work on
- practice-branch: a second branch. Check whether your import copied it.
- v1.0: a tag marking the first release
